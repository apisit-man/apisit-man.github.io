# 🔍 เกมจับผิดภาพออนไลน์ - ยอดนักสืบสายตาเหยี่ยว (Spot The Difference Game)

เว็บเกมจับผิดภาพออนไลน์ 10 ด่าน พัฒนาด้วย **Pure HTML5 + CSS3 + Vanilla JavaScript** แบบ 100% Client-Side ออกแบบมาเพื่อเล่นบน **GitHub Pages** หรือเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์

---

## 🌟 ฟีเจอร์เด่น
- **เหมาะสำหรับทุกเพศทุกวัย:** ทั้งนักเรียนระดับประถมศึกษา มัธยมศึกษาตอนต้น และคนทั่วไป
- **2 โหมดการเล่น:**
  - 🌿 **โหมดฝึกหัด (Casual Mode):** เล่นชิวๆ สบายๆ ไม่จำกัดเวลา มีคำใบ้ 5 ครั้ง เหมาะกับเด็กประถมเพื่อฝึกสมาธิ
  - ⚡ **โหมดท้าทาย (Challenge Mode):** แข่งกับเวลา 60 วินาที พร้อมระบบหัวใจ 3 ดวง ❤️❤️❤️
- **ระบบเสียงสังเคราะห์ในตัว (Web Audio API):** มีเสียงคลิกถูก เสียงคลิกผิด และเสียงไชโยฉลองชัย โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก โหลดเร็วและไม่มีปัญหาเสียงหาย
- **ระบบเอฟเฟกต์ฉลอง (Confetti Animation):** แสดงผลพลุริบบิ้นเมื่อหาจุดต่างสำเร็จ
- **เกียรติบัตรยอดนักสืบสายตาเหยี่ยว (Certificate Generator):** เมื่อเล่นผ่านครบ 10 ด่าน ผู้เล่นสามารถพิมพ์ชื่อและกดดาวน์โหลดภาพเกียรติบัตร (PNG) เก็บไว้เป็นที่ระลึกหรือส่งให้คุณครูได้ทันที
- **บันทึกความก้าวหน้าอัตโนมัติ (LocalStorage):** ปลดล็อกด่านและสะสมดาว ⭐ สูงสุด 30 ดวง

## 🚀 วิธีนำขึ้นเล่นออนไลน์ผ่าน GitHub Pages (3 ขั้นตอน)

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. ไปที่ [GitHub.com](https://github.com) แล้วลงชื่อเข้าใช้
2. คลิกปุ่ม **New** (หรือเครื่องหมาย `+` มุมบนขวา) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น `spot-the-difference`
4. เลือกเป็น **Public** แล้วกด **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์ขึ้น GitHub
คุณสามารถเลือกวิธีใดวิธีหนึ่ง:
- **วิธีที่ 1 (ผ่านหน้าเว็บง่ายสุด):**
  - ในหน้า Repository ใหม่ กดปุ่ม **uploading an existing file**
  - ลากไฟล์ `index.html`, `style.css`, `game.js`, `README.md` และโฟลเดอร์ `assets` เข้าไปวาง
  - กด **Commit changes**
- **วิธีที่ 2 (ผ่าน Git Command Line):**
  ```bash
  cd spot-the-difference-game
  git init
  git add .
  git commit -m "Initial commit: Spot The Difference Game"
  git branch -M main
  git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/spot-the-difference.git
  git push -u origin main
  ```

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ในหน้า Repository ของคุณ ให้คลิกที่แท็บ **Settings** (รูปฟันเฟืองด้านบน)
2. แถบเมนูด้านซ้าย ให้คลิกที่ **Pages**
3. ภายใต้หัวข้อ **Build and deployment**:
   - ช่อง **Source** เลือกเป็น `Deploy from a branch`
   - ช่อง **Branch** เลือกเป็น `main` และโฟลเดอร์ `/ (root)`
   - คลิกปุ่ม **Save**
4. รอประมาณ 1–2 นาที หน้าเว็บจะแสดงลิงก์สีเขียว:
   ```text
   Your site is live at https://<ชื่อผู้ใช้ของคุณ>.github.io/spot-the-difference/
   ```
5. คลิกเปิดลิงก์ หรือส่งลิงก์นี้ให้นักเรียนและเพื่อนๆ เข้ามาเล่นได้ทันที!
