# ภาพปริศนา 3 ภาพ 1 คำ — ฉบับแก้ไขพร้อมใช้งาน (60 ข้อ)

**วันที่จัดทำ:** 16 ตุลาคม 2569  
**เว็บไซต์เป้าหมาย:** `https://apisit-man.github.io/projects/thai-word-puzzle/index.html`

## เริ่มเล่นทันที

1. แตกไฟล์ ZIP ทั้งหมดก่อน
2. เปิด `index.html` ใน Chrome, Edge หรือ Firefox
3. ต้องเก็บโฟลเดอร์ `assets/` ไว้ข้าง ๆ `index.html` เสมอ (ไม่ต้องใช้เซิร์ฟเวอร์)

## นำไปแทนที่เกมเดิมบน GitHub Pages

1. **สำรอง** โฟลเดอร์ `projects/thai-word-puzzle/` ของ repository เดิมก่อน
2. แตก ZIP ที่ดาวน์โหลดมา
3. คัดลอกไฟล์ `index.html` และโฟลเดอร์ `assets/` ทั้งโฟลเดอร์ ไปไว้ที่ `projects/thai-word-puzzle/` โดยยอมรับการแทนที่ไฟล์ชื่อซ้ำ
4. แนะนำคัดลอกโฟลเดอร์ `data/` เพื่อเก็บต้นฉบับโจทย์ไว้แก้ไขในอนาคตด้วย (ตัวเกมไม่จำเป็นต้องโหลด JSON แยก)
5. Commit และ push ไปยัง branch ที่ GitHub Pages ใช้อยู่ แล้วเปิดเว็บไซต์ตรวจสอบในโหมดไม่เก็บแคช (`Ctrl + Shift + R`)

**สำคัญ:** ชุดนี้เป็น **ฉบับแทนที่ไฟล์เกมครบชุด** ไม่ต้องเพิ่ม `expansion/upgrade.js` แบบแพ็กก่อนหน้านี้ และไม่ต้องเก็บโฟลเดอร์ `expansion/` อีก เพราะโจทย์ใหม่ทั้งหมดถูกรวมเข้ากับ `index.html` แล้ว

## เนื้อหา

- 60 ข้อ: อาหารและเครื่องปรุง, เครื่องดื่ม, สิ่งของและของใช้, ธรรมชาติ สัตว์ และสำนวน **หมวดละ 15 ข้อ**
- ภาพ 180 ไฟล์ ครบทุกช่อง — ปรับ/วาดภาพใหม่จำนวน **147 ภาพ**; เก็บภาพเดิมที่ชัดเจน **33 ภาพ**
- แก้การแบ่งคำและคำอธิบายที่ไม่ตรงเฉลย โดยเฉพาะ Q11, Q12, Q30, Q41, Q42, Q50–Q59
- ข้อที่มีคำตอบ 2 ส่วนหรือสำนวน ใช้คำอธิบาย **ภาพเบาะแส / ภาพเล่าเหตุการณ์** ไม่อ้างว่าภาพทั้งสามเป็น 3 คำต่อกันแบบตรงตัว
- ปรับภาพเสี่ยงสื่อผิด ได้แก่ Q15, Q18, Q32, Q39, Q43, Q45, Q47, Q48 เป็นต้น

## ระบบเกม

- ตอบผิดแล้ว **ไม่แสดงเฉลย** และยังลองใหม่ได้
- คำตอบทางเลือกที่กำหนดไว้ในแต่ละข้อได้รับการยอมรับเทียบเท่าคำหลัก
- เวลาหมดจะหยุดให้ตอบ แต่ **ไม่เปิดคำเฉลยเอง** ผู้เล่นเลือกดูเฉลยได้
- ขอคำใบ้ได้ 2 ครั้ง โดยมีผลต่อคะแนน
- เล่นครบชุดมีหน้าสรุปผล พร้อมเริ่มใหม่
- เลือกหมวด, ปิดเปิดเสียง, โหมดมืด และขยายภาพ
- **โหมดครู** แสดงคำตอบหลัก/คำตอบทางเลือก/หมายเหตุโจทย์ และส่งออกรายการคำตอบเสนอของผู้เล่นเป็น CSV
- เก็บคำตอบที่ผู้เล่นเสนอบนอุปกรณ์ด้วย `localStorage` เท่านั้น ไม่ส่งข้อมูลออกอินเทอร์เน็ต

## แก้คำตอบหรือเพิ่มคำยอมรับ

ข้อมูลฉบับที่อ่านง่ายอยู่ที่ `data/puzzles.json` โดยใช้ฟิลด์ `answer` และ `acceptedAnswers` แต่เกมอ่านข้อมูลจาก `<script id="embeddedData" ...>` ใน `index.html` เพื่อรองรับการเปิดแบบออฟไลน์ได้ทันที ถ้าแก้ `puzzles.json` แล้ว **ต้องอัปเดตข้อมูลใน `index.html` ให้ตรงกันด้วย** — การแก้ JSON อย่างเดียวไม่เปลี่ยนเกม

## ข้อจำกัดและการตรวจสอบ

ภาพในชุดนี้ได้ตรวจว่ามีครบ ขนาดเหมาะสม และคำแบ่ง/ไฟล์ภาพเชื่อมโยงถูกต้อง รวมถึงทดสอบการโต้ตอบใน Chromium แล้ว แต่ **ยังไม่ผ่านการทดสอบความกำกวมกับผู้เล่นจริง** แนะนำให้ครูทดลองกับผู้เล่น 10–15 คนก่อนใช้เป็นแบบประเมินที่มีคะแนนอย่างเป็นทางการ และใช้ข้อมูลคำตอบทางเลือกเพิ่มเติมปรับปรุงภายหลัง
