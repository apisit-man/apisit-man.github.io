# QA: เกมภาพปริศนา 3 ภาพ 1 คำ เวอร์ชัน 60 ข้อ

## สิ่งที่แก้แล้ว

- [x] โจทย์ 60 ข้อ / 4 หมวด × 15 ข้อ ไม่มีรหัสซ้ำ
- [x] อ้างอิงภาพถูกต้องครบ 180 ช่อง
- [x] ภาพจากโปสเตอร์ที่ถูกครอปจนวัตถุขาดถูกแทนที่ในชุดขยาย 36 ข้อ
- [x] จุดที่ทำให้คำเฉลยปรากฏในภาพเดียว ได้ปรับภาพใหม่ในข้อที่วิเคราะห์ไว้
- [x] Q11, Q12 เปลี่ยนส่วนคำเป็น แปรง+สี+ฟัน และ ยา+สี+ฟัน
- [x] Q30, Q41, Q42 ไม่อ้างว่าคำบอกบริบทในภาพ 3 เป็นส่วนของคำเฉลย
- [x] Q50, Q51, Q52, Q54, Q55, Q57, Q58, Q59 ปรับคำอธิบายเป็นความสัมพันธ์ของภาพ/สำนวน
- [x] Q32 วาดผลฝรั่งใหม่ไม่ให้มีผลแตงโมปน
- [x] Q47 เปลี่ยนภาพเป็นแว่นธรรมดาไม่ใช่แว่นกันแดดสำเร็จรูป
- [x] แก้โค้ดตรวจคำตอบ: ผิดไม่เปิดเฉลย, อนุญาตลองซ้ำ, จับเวลาต่อ, รับ alias
- [x] ทดสอบ JavaScript syntax และ interaction ด้วย Chromium
- [x] ไม่มี external JS หรือภาพที่ต้องโหลดจาก CDN

## ทดสอบแล้วในเบราว์เซอร์ (Chromium แบบ in-memory)

1. หน้าแสดงโจทย์ทั้งหมด 60 ข้อ
2. แสดงภาพ 3 ช่อง
3. คำตอบผิดแล้วไม่มีเฉลยแสดง; ช่องตอบยังใช้งานได้
4. กดใบ้แล้วข้อความขึ้น
5. ตอบถูกแล้วแสดงคำเฉลยและคะแนน
6. กดข้อต่อไป/เลือกหมวดเหลือ 15 ข้อ
7. เปิด/ปิดภาพขยายด้วย Escape
8. เปลี่ยนโหมดมืดและเปิดโหมดครู
9. ไม่พบ JavaScript runtime error

หมายเหตุ: ระบบเบราว์เซอร์ทดสอบนี้ถูกจำกัดการนำทางไปยัง file:// หรือ localhost จึงทดสอบโดยโหลด HTML ลงหน้าเบราว์เซอร์โดยตรง ตรวจภาพจากไฟล์แยกต่างหาก ไม่ได้ทดสอบการเผยแพร่บน GitHub Pages จริง

## ที่ยังควรทดสอบกับคนจริง

- [ ] สำรวจภาพกำกวมกับผู้เล่น 10–15 คน
- [ ] ตรวจระดับความยาก Q34, Q39, Q51–Q60 โดยเฉพาะภาพเชิงเปรียบเทียบ
- [ ] ใช้ข้อเสนอคำตอบทางเลือกของผู้เล่นในโหมดครูทบทวน alias ก่อนใช้สอบหรือแข่งขันจริง
