# รายงานการตรวจภาพปริศนา

ตรวจสอบการมีอยู่ของไฟล์ ขนาด 640×640 พื้นหลัง RGBA และความสอดคล้องภาพกับคำที่ตั้งใจสื่อแบบเบื้องต้นเท่านั้น ยังไม่ได้ทดสอบกับผู้เล่นจริง

## ผ่านตรวจภาพเบื้องต้น

- **Q01 ข้าวผัดกุ้ง** — ข้าว + ผัด + กุ้ง; ภาพผัดเป็นผักล้วน ไม่เฉลยคำว่ากุ้ง
- **Q02 ข้าวต้มปลา** — ข้าว + ต้ม + ปลา; ภาพต้มเป็นหม้อน้ำเดือด
- **Q03 ข้าวไข่ดาว** — ข้าว + ไข่ + ดาว; ใช้การรวมคำแบบปริศนา ไม่ใช้ภาพไข่ดาวสำเร็จรูป
- **Q04 ข้าวหมูแดง** — ข้าว + หมู + แดง; สีแดงเป็นหยดสี ไม่ใช่หมูแดงสำเร็จรูป
- **Q06 น้ำส้มคั้น** — น้ำ + ส้ม + คั้น; ภาพคั้นเป็นเครื่องคั้นส้ม
- **Q07 น้ำผึ้งมะนาว** — น้ำ + ผึ้ง + มะนาว; ใช้ผึ้งแทนน้ำผึ้ง เป็นการต่อคำ
- **Q09 ถุงมือยาง** — ถุง + มือ + ยาง; ภาพยางเป็นหนังยาง; สื่อคำว่ายาง
- **Q17 พริกไทยดำ** — พริก + ไทย + ดำ; ภาพสีดำเป็นสัญลักษณ์สี
- **Q20 ผีเสื้อกลางคืน** — ผี + เสื้อ + กลางคืน; ภาพกลางคืนมีพระจันทร์และดวงดาว
- **Q21 แก้วตาดวงใจ** — แก้ว + ตา + ดวงใจ; ดวงใจแสดงด้วยสัญลักษณ์หัวใจ
- **Q24 พริกน้ำปลา** — พริก + น้ำ + ปลา; เป็นการต่อคำแบบปริศนา ไม่ใช่ภาพส่วนผสมตามจริง

## ควรทดสอบกับผู้เล่น

- **Q05 ไข่เจียวหมูสับ** — ไข่ + เจียว + หมูสับ; ภาพเจียวเป็นไข่เจียวแล้วและอาจใบ้คำเกินไป
- **Q08 ผัดไทยกุ้งสด** — ผัด + ไทย + กุ้งสด; ภาพกุ้งจากตารางขนาดเล็ก อาจยังดูคล้ายกุ้งปรุงสุก
- **Q10 ไม้ขีดไฟ** — ไม้ + ขีด + ไฟ; ภาพขีดเป็นการขีดไม้ขีด อาจทำให้เดาคำเต็มเร็ว
- **Q13 รถเข็นเด็ก** — รถ + เข็น + เด็ก; ภาพเข็นแสดงรถเข็นเด็กอยู่แล้ว อาจเฉลยบางส่วน
- **Q14 รถเก็บขยะ** — รถ + เก็บ + ขยะ; ภาพรถคันแรกเป็นรถขยะเต็มคัน อาจเฉลยเร็ว
- **Q16 กระดาษห่อของขวัญ** — กระดาษ + ห่อ + ของขวัญ; ภาพห่อเป็นกระดาษห่อของขวัญ อาจใบ้คำมากไป
- **Q19 ดอกไม้ไฟ** — ดอก + ไม้ + ไฟ; ภาพดอกไม้อาจถูกอ่านว่า 'ดอกไม้' ไม่ใช่ 'ดอก'
- **Q22 ปลาทอดกระเทียม** — ปลา + ทอด + กระเทียม; ภาพทอดจากตารางมีวัตถุดิบในกระทะ อาจใบ้คำมาก
- **Q23 รุ้งกินน้ำ** — รุ้ง + กิน + น้ำ; ภาพกินแสดงเด็กดื่มน้ำ ซึ่งบางคนอาจอ่านว่า 'ดื่ม'

## ต้องปรับภาพก่อนเผยแพร่

- **Q11 แปรงสีฟัน** — แปรง + สีฟัน + ฟัน; ภาพกลางเป็นยาสีฟัน ไม่ได้แสดงกริยาสีฟันอย่างชัดเจน
- **Q12 ยาสีฟัน** — ยา + สีฟัน + ฟัน; ภาพกลางยังไม่แสดงกริยาแปรงฟัน และการแบ่งคำอาจซ้ำซ้อน
- **Q15 หม้อหุงข้าว** — หม้อ + หุง + ข้าว; ภาพกลางเป็นหม้อหุงข้าวสำเร็จรูป จึงเฉลยคำตอบในภาพเดียว
- **Q18 น้ำตาลทราย** — น้ำ + ตาล + ทราย; ภาพสุดท้ายคล้ายน้ำตาล/แป้ง ไม่ใช่ทรายชัดเจน
