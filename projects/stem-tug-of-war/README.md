# STEM Tug of War — Classroom Edition v1.0

เกมชักเย่อประลองความคิดด้าน STEM และเทคโนโลยี สำหรับนักเรียนสองทีมเล่นพร้อมกันบนหน้าจอเดียว

## เล่นทันที
- **สะดวกที่สุด:** เปิดไฟล์ `STEM_Tug_of_War_Standalone.html` ด้วย Chrome, Edge หรือ Safari (ไฟล์นี้อยู่ข้าง ZIP และยังเปิดได้แบบออฟไลน์)
- **ขึ้น GitHub Pages:** แตกไฟล์ ZIP แล้วอัปโหลด `index.html` และโฟลเดอร์ `css/`, `js/`, `data/` ไปยัง root ของ repository (หรือลงในโฟลเดอร์ `/docs` แล้วตั้ง Pages ตามตำแหน่งนั้น) จากนั้นเปิดใช้งาน GitHub Pages
- หน้าแรก → เริ่มการแข่งขัน → เลือกหมวดและตั้งชื่อทีม → เริ่มเกม
- บนกระดาน Interactive Whiteboard ให้แต่ละทีมกดตัวเลือกทางฝั่งของตน

## กติกา
- รอบละ 60 วินาที
- ตอบถูก: เชือกขยับเข้าฝั่งผู้ตอบ **1 ระดับ**
- ตอบผิด: เชือกขยับไปฝั่งตรงข้าม **0.5 ระดับ**
- ใครดึงเชือกครบ **6 ระดับ** ชนะรอบ หรือเมื่อหมดเวลาให้ตัดสินจากตำแหน่งเชือก
- ชนะ **2 รอบ** ก่อนเป็นผู้ชนะทั้งเกม หากตำแหน่งเป็น 0 เมื่อหมดเวลาถือว่าเสมอและแข่งต่อในรอบถัดไป
- โปรแกรมคำนวณโดยใช้หน่วยครึ่งระดับ (-12 ถึง +12) เพื่อป้องกันความคลาดเคลื่อนของทศนิยม

## เนื้อหา
- 100 ข้อภาษาไทย 5 หมวด หมวดละ 20 ข้อ: ระบบเทคโนโลยี, กระบวนการออกแบบ, วัสดุและสมบัติ, กลไกและแรง, ข้อมูลและการตัดสินใจ
- เลือกระดับพื้นฐาน / ปานกลาง / ท้าทาย / ผสมได้
- สุ่มคำถามแยกสองทีม โดยจับคู่โจทย์หมวดและระดับความยากเดียวกันเมื่อเป็นไปได้
- หน้าสรุปผลมีคำอธิบายคำตอบผิดสำหรับการอภิปรายหลังแข่งขัน
- ข้อความโจทย์ควรผ่านการตรวจทานและเลือกตามระดับชั้นที่สอนจริง

## Teacher Studio
- เพิ่ม แก้ไข และลบโจทย์ได้บนหน้าเว็บ
- บันทึกการแก้ไขใน `localStorage` ของเบราว์เซอร์ที่ใช้อยู่ (ไม่ซิงโครไนซ์ข้ามอุปกรณ์)
- **ส่งออก JSON** เพื่อสำรองข้อมูลและย้ายชุดคำถาม
- **นำเข้า JSON** แบบเป็นรายการ array หรือ `{ "questions": [ ... ] }`; รหัส ID ซ้ำจะอัปเดตคำถามเดิม
- เฉลยคำตอบใช้ `correctIndex` เริ่มตั้งแต่ 0 (A) ถึง 3 (D)
- ถ้าต้องการให้แก้ไขคลังคำถามเริ่มต้นให้ผู้ใช้ทุกคนเห็นบน GitHub Pages ให้อัปเดต `js/questions.js` แล้วเผยแพร่ไฟล์ใหม่ หรือแจกไฟล์ JSON ให้ครูนำเข้า

## ความต้องการของอุปกรณ์
- Chrome / Edge / Safari รุ่นใหม่, แนวนอน 16:9 หรือจอแท็บเล็ต
- การแตะพร้อมกันขึ้นอยู่กับความสามารถ Multi-touch ของจอและไดรเวอร์
- เวอร์ชันนี้เล่นสองทีมบน **จอเดียว** ไม่ใช่เกมสองมือถือแบบออนไลน์
- ไม่มีฐานข้อมูลหรือระบบเก็บข้อมูลเด็ก/บัญชีผู้ใช้
- เสียงสร้างจาก Web Audio และเล่นได้เมื่อผู้ใช้กดเริ่มเกม; ปุ่ม ♫ เปิด/ปิดเสียง
- ฟอนต์บนเว็บไซต์โหลด Noto Sans Thai / Outfit เมื่อเชื่อมต่ออินเทอร์เน็ต; HTML แบบไฟล์เดียวใช้ฟอนต์ในเครื่องเป็น fallback

## สถานะ
Implemented: เกมสองทีม, timer/pause, scoring, rope animation, 100 questions, results & debrief, local teacher editor, import/export JSON, responsive layout, fullscreen and audio. Multiplayer ข้ามอุปกรณ์และผู้ใช้หลายคนยังไม่อยู่ในเวอร์ชันนี้

## ชุดทดสอบที่ผ่าน (Chromium headless)
- ตรวจคำถาม 100 ข้อ หมวดละ 20 ข้อ และตรวจ schema/ID
- ตรวจบวก/ลบระดับเชือก จุดเส้นชัย และการตัดสินชนะ 2 รอบ
- เล่นจริงจนทีมหนึ่งชนะ 2 รอบ, เล่นใหม่, และทดสอบคำตอบสองฝั่ง
- ทดสอบหยุดเวลาและเล่นต่อ
- จำลองครบเวลา 60 วินาที → ผลเสมอเมื่อเชือกอยู่กลางสนาม
- ตรวจ Teacher Studio: เพิ่ม แก้ไข ลบ นำเข้า ส่งออก รีเซ็ต
- ตรวจการแสดงผลที่ 1440×900 และ 390×844 โดยไม่พบ JavaScript Error

**หมายเหตุ:** การทดสอบผ่านเบราว์เซอร์แบบจำลองยังไม่เท่ากับการทดสอบจอ Multi-touch ของแต่ละโรงเรียน ควรทดลองบนจอจริงก่อนจัดการแข่งขันในชั้นเรียน
