🧠 คิดแบบนักวิทยาการคำนวณ (Computational Thinking)

วิธีการเล่น & กฎทฤษฎีกราฟ

1. แตะค้าง/คลิกที่ ช่องสีชมพูกระพริบ เพื่อเริ่มเดินเส้น
2. ลากระบายเส้นนีออนให้ผ่าน ทุกช่องว่างครบ 100% (วิถีแฮมิลตัน)
3. ห้ามลากผ่าน สิ่งกีดขวาง (✕) และห้ามเดินทับรอยเดิม
4. ลูกศรสีส้ม (One-Way Digraph): อนุญาตให้เดินผ่านได้เฉพาะทิศทางที่ลูกศรชี้เท่านั้น
5. จุดตรวจตัวเลข ①, ②... (Waypoints): ต้องเดินเก็บเรียงลำดับตัวเลข 1 ไป 2 ไป 3...
6. ลากกลับทางเดิม หรือกดปุ่ม Undo (Z) เพื่อถอยทีละก้าว
7. บนคอมพิวเตอร์: สามารถใช้ ปุ่มลูกศร / WASD เดินเส้นได้อย่างคล่องแคล่ว

🎯 มโนมติทางคณิตศาสตร์ & วิทยาการคำนวณ (Computational Thinking):
• Hamiltonian Path (วิถีแฮมิลตัน): การค้นหาเส้นทางเดินผ่านทุกจุดยอด (Vertices) ในกราฟโดยไม่ซ้ำ
• Directed Graphs (กราฟระบุทิศทาง): กฎข้อจำกัดทางเดียว (One-way Constraints) ในการไหลของเครือข่าย
• Topological Sorting & Checkpoints: การวางแผนลำดับขั้นตอนแบบมีเงื่อนไขก่อน-หลัง
• Warnsdorff's Heuristic: การเลือกเดินเข้าหาจุดยอดที่มี Degree น้อยที่สุดก่อน เพื่อป้องกันการติดทางตัน

⚖️ สรุปมโนมติ: Eulerian Path vs. Hamiltonian Path
Eulerian Path (วิถีออยเลอร์)
เดินผ่าน ทุกเส้นเชื่อม (Edges) ให้ครบพอดี โดยไม่ซ้ำเส้นทาง
ความซับซ้อน: O(E) (โจทย์ง่าย P)
ทฤษฎีบท: มีจุดยอดดีกรีคี่ได้ไม่เกิน 2 จุด
Hamiltonian Path (วิถีแฮมิลตัน - เกมนี้!)
เดินผ่าน ทุกจุดยอด (Vertices) ให้ครบพอดี โดยไม่ซ้ำช่อง
ความซับซ้อน: NP-Complete (โจทย์ท้าทาย)
ต้องใช้ Heuristics, Backtracking & Decomposition
