X (Twitter) Video Downloader
เครื่องมือเปิดตัวเลือกดาวน์โหลดวิดีโอ

วางลิงก์โพสต์จาก X (Twitter) เพื่อพรีวิวและดาวน์โหลดไฟล์วิดีโอ MP4 ได้โดยตรงภายในหน้านี้ ใช้งานได้บน GitHub Pages โดยไม่ต้องติดตั้งโปรแกรมหรือเปิดเซิร์ฟเวอร์ในเครื่อง

✨
ใช้งานผ่าน GitHub Pages ได้โดยตรง 100%
ดึงข้อมูลไฟล์วิดีโอ MP4 จากโพสต์ X/Twitter สาธารณะพร้อมตัวเลือกความละเอียด (HD / SD) ให้กดบันทึกไฟล์ลงเครื่องได้ทันทีโดยไม่มีโฆษณาคั่น

รองรับรูปแบบ x.com/ชื่อผู้ใช้/status/เลขโพสต์ และ twitter.com/... ใช้เฉพาะเนื้อหาที่คุณมีสิทธิ์ดาวน์โหลด

ตัวเลือกดาวน์โหลดวิดีโอ MP4

กดปุ่มความละเอียดที่ต้องการเพื่อบันทึกไฟล์ .mp4 ลงเครื่องโดยตรง หรือดูตัวอย่างวิดีโอด้านล่าง

ไม่ต้องใช้ Backend

ทำงานบน GitHub Pages ทันที ไม่ต้องเปิด Python Server และไม่ต้องใส่ API Key
