หน้าแรก / แบบจำลองวิทย์-การแพทย์ / การแทรกสอดของคลื่น (Wave Interference)

การจำลองการแทรกสอดของคลื่น 2 แหล่งกำเนิด (Double-Source Interference)

⚡ สมการคลื่น PDE 2D
สัญลักษณ์ความสูง & สีคลื่น
สันคลื่น: คลื่นนูน ($+u$)
ท้องคลื่น: คลื่นต่ำ ($-u$)
แนวบัพ: ผิวนิ่ง ($u \approx 0$)

💡 คลิกบนผืนน้ำเพื่อหยดน้ำสร้างคลื่นรบกวน

📖 หลักการทางฟิสิกส์ของการแทรกสอด (Wave Interference Physics)

การจำลองนี้คำนวณจาก สมการคลื่นใน 2 มิติ (2D Wave Equation via Finite Difference Method):

$$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$$

โดยปรากฏการณ์การเสริมกัน (Constructive) และการหักล้างกัน (Destructive) เกิดขึ้นจากการซ้อนทับกันของหน้าคลื่นทรงกลมที่แผ่ออกจากจุดกำเนิดทั้งสองตามธรรมชาติ

แนวปฏิบัพ (Antinodal Line):

ผลต่างระยะทางเป็นจำนวนเต็มความยาวคลื่น $|S_1P - S_2P| = n\lambda$ คลื่นแทรกสอดเสริมกัน สั่นด้วยแอมพลิจูดสูงสุด

แนวบัพ (Nodal Line):

ผลต่างระยะทาง $|S_1P - S_2P| = \left(n - \frac{1}{2}\right)\lambda$ สันคลื่นซ้อนทับท้องคลื่น หักล้างกันจนผิวน้ำนิ่งสนิท

กรณีศึกษาจำลอง (Presets) 4 โหมด
ตัวแปรการทดลอง (Control Variables)
ระยะห่างแหล่งกำเนิด ($d$) 60 px
ความถี่การสั่น ($f$) 0.24 Hz
ผลต่างเฟส ($\Delta\phi$) 0° (ร่วมเฟส)
แอมพลิจูด ($A$) 7.0
ความชันผิวน้ำ 3D (Elevation Gain) 3.5x
วิเคราะห์ผลทางฟิสิกส์ (Live Physics)
ความยาวคลื่น ($\lambda$): 20.8 px
อัตราส่วน $d / \lambda$: 2.88
จำนวนแนวปฏิบัพ ($N_{\text{max}}$): 5 แนว
เส้นกึ่งกลาง ($L_0$): ปฏิบัพกลาง ($A_0$)
