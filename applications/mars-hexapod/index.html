🚀 ภารกิจสำรวจดาวอังคาร Chryse Planitia

ยินดีต้อนรับสู่นวัตกรรมหุ่นยนต์สำรวจ 6 ขา ARES-6 ในพื้นที่แอ่งหลุมอุกกาบาต Chryse Planitia บนดาวอังคาร ซึ่งมีทั้งแนวหินบะซอลต์แหลมคม เนินทราย และขอบผาสูงชันที่ยานล้อยางทั่วไปไม่สามารถเข้าถึงได้

🎯 เป้าหมายภารกิจ (Mission Objectives):
1. ขับหุ่นยนต์ ARES-6 ไปยังจุดสัญญาณเลเซอร์ 4 จุด เพื่อสแกนเก็บตัวอย่างแร่
2. สังเกตการทำงานของระบบ Active Chassis Leveler ที่คอยปรับมุม Pitch/Roll ของลำตัวให้ระนาบกับพื้นผิว
3. สลับเป็น Wave Gait เมื่อต้องไต่เนินหินสูงชันเพื่อการทรงตัวสูงสุด
4. เดินทางกลับสู่ยานขึ้นสู่วงโคจร MAV Lander เพื่อส่งมอบตัวอย่างและจบภารกิจ!
🕹️ วิธีควบคุม:
• W / A / S / D หรือ ปุ่มลูกศร: เดินหน้า ถอยหลัง เลี้ยวซ้าย/ขวา
• L: สลับเปิด/ปิดระบบ Leveler (ลองปิดดูเพื่อสัมผัสความสั่นไหวของตัวถัง!)
• G: สลับรูปแบบการก้าวเดิน (Tripod Gait วิ่งไว / Wave Gait ไต่หินมั่นคง)
• สมาร์ทโฟน/แท็บเล็ต: ลากจอยสติ๊กสัมผัสด้านล่างซ้าย

🔬 STEM Robotics Kinematics Inspector

1. อัลกอริทึมการคำนวณระนาบค้ำยัน (Plane Fitting):

หุ่นยนต์ใช้พิกัด 3 มิติของเท้าที่สัมผัสพื้น (Stance Feet) 3 จุด $(p_1, p_2, p_3)$ มาสร้างระนาบค้ำยันใน Three.js:

tempPlane.setFromCoplanarPoints(p1, p2, p3);
normal = tempPlane.normal; // เวกเตอร์แนวตั้งฉากของระนาบ

2. การคำนวณมุมเอียง Pitch & Roll ด้วยตรีโกณมิติ:

แปลงเวกเตอร์แนวฉาก $\vec{N} = (n_x, n_y, n_z)$ ให้เป็นมุมก้มเงยและมุมเอียงลำตัว:

targetPitch = Math.atan2(normal.z, normal.y); // มุมก้มเงยแกน X
targetRoll = -Math.atan2(normal.x, normal.y); // มุมเอียงข้างแกน Z

3. ตัวกรองความถี่ต่ำเพื่อลดการสั่นไหว (Exponential Smoothing Filter):

ป้องกันลำตัวกระตุกเมื่อเท้าแตะหินขรุขระด้วยสมการ Low-Pass Damping:

currentPitch += (targetPitch - currentPitch) * damping;
currentRoll += (targetRoll - currentRoll) * damping; // damping = 0.08
โครงสร้าง Kinematics อ้างอิงงานวิจัยหุ่นยนต์ชีวลอกเลียนแบบ (Biomimetic Robotics) ในชั้นเรียนวิทยาศาสตร์และเทคโนโลยีคำนวณ
