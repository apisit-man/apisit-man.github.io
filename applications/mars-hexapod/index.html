🚀 ภารกิจสำรวจดาวอังคาร Chryse Planitia

ยินดีต้อนรับสู่นวัตกรรมหุ่นยนต์สำรวจ 6 ขา ARES-6 ในพื้นที่ Chryse Planitia (ที่ราบลุ่มต่ำและแอ่งทางน้ำหลากโบราณ ใกล้จุดลงจอดประวัติศาสตร์ของไวกิง 1 ปี 1976) ซึ่งเต็มไปด้วยหินบะซอลต์ ผาหินสูงชัน และร่องรอยการกัดเซาะที่ท้าทายยานสำรวจล้อยาง

🎯 คำถามวิจัยหลัก & เป้าหมายภารกิจ (Scientific Inquiry Objectives):
"หลักฐานทางวิทยาศาสตร์ใดที่ยืนยันได้ว่า ในอดีต Chryse Planitia เคยมีน้ำของเหลวคงตัวอยู่ยาวนาน?"

1. ขับหุ่นยนต์ไปยังจุดตรวจวัด 4 แหล่งแร่ปริศนา เพื่อสแกนสเปกตรัมอินฟราเรด (VNIR Spectroscopy) และเลือกข้อสรุปทางธรณีวิทยาที่ถูกต้อง
2. ทำการทดลอง Active Chassis Leveler A/B Test บันทึกข้อมูลเปรียบเทียบการลดแรงเอียงตัวถัง
3. ศึกษาฟิสิกส์พลังงานแสงอาทิตย์ตามมุมตกกระทบ $\cos\theta$ และตรวจวัดความดันบรรยากาศ 0.63 kPa ณ จุดร่วมสามของน้ำ
4. เดินทางกลับสู่ยาน MAV Lander เพื่อสังเคราะห์รายงานสรุปข้อค้นพบตามระเบียบวิธี CER (Claim-Evidence-Reasoning)
🕹️ วิธีควบคุม & การปรับมุมมอง:
• WASD หรือ ปุ่มลูกศร / D-Pad: บังคับทิศทางตามมุมมองของผู้ใช้ (กดขึ้น=เดินตามสายตา, กดลง=เข้าหากล้อง, ซ้าย/ขวา=ซ้าย/ขวาของจอ)
• R หรือ ปุ่ม STEER: สลับโหมดทิศทาง (ตามมุมมองกล้อง หรือ ตามหัวหุ่นยนต์แบบ Tank)
• 🖱️ ลากเมาส์ & หมุนลูกกลิ้ง: หมุนมุมมองพื้นผิวดาว 360° และซูมเข้า-ออกได้อย่างอิสระ
• C หรือ ปุ่ม CAM: สลับ 4 โหมดมุมกล้อง (อิสระ 360° / มุมสูงโดรน / เสายาน POV / ตรวจสภาพ)
• F: โหมดเต็มจอ (Fullscreen)  |  L: สลับเปิด/ปิดระบบ Leveler  |  G: สลับโหมดก้าวเดิน (Tripod/Wave)  |  E: ห้องทดลองวิทย์
• Spacebar: เบรกฉุกเฉินหยุดหุ่นทันที

🔬 STEM Robotics Kinematics Inspector

1. อัลกอริทึมการคำนวณระนาบค้ำยัน (Plane Fitting):

หุ่นยนต์ใช้พิกัด 3 มิติของเท้าที่สัมผัสพื้น (Stance Feet) 3 จุด $(p_1, p_2, p_3)$ มาสร้างระนาบค้ำยันใน Three.js:

tempPlane.setFromCoplanarPoints(p1, p2, p3);
normal = tempPlane.normal; // เวกเตอร์แนวตั้งฉากของระนาบ

2. การคำนวณมุมเอียง Pitch & Roll ด้วยตรีโกณมิติ:

แปลงเวกเตอร์แนวฉาก $\vec{N} = (n_x, n_y, n_z)$ ให้เป็นมุมก้มเงยและมุมเอียงลำตัว:

targetPitch = Math.atan2(normal.z, normal.y); // มุมก้มเงยแกน X
targetRoll = -Math.atan2(normal.x, normal.y); // มุมเอียงข้างแกน Z

3. ตัวกรองความถี่ต่ำเพื่อลดการสั่นไหว (Exponential Smoothing Filter):

ป้องกันลำตัวกระตุกเมื่อเท้าแตะหินขรุขระด้วยสมการ Low-Pass Damping:

currentPitch += (targetPitch - currentPitch) * damping;
currentRoll += (targetRoll - currentRoll) * damping; // damping = 0.08
โครงสร้าง Kinematics อ้างอิงงานวิจัยหุ่นยนต์ชีวลอกเลียนแบบ (Biomimetic Robotics) ในชั้นเรียนวิทยาศาสตร์และเทคโนโลยีคำนวณ

🦵 การวิเคราะห์การเคลื่อนที่: Tripod Gait vs Wave Gait

หุ่นยนต์ 6 ขามีรูปแบบการก้าวเดินชีวลอกเลียนแบบ (Biomimetic Gaits) ให้เลือกใช้ตามสภาพภูมิประเทศ ซึ่งมีความสัมพันธ์เชิงแลกเปลี่ยน (Trade-off) ระหว่างความเร็วและความมั่นคง:

🚀 Tripod Gait (ก้าวสลับสามขา)
• จำนวนขาค้ำพื้น: 3 ขาค้ำ / 3 ขาก้าวลอย
• Duty Factor (β): 0.50
• ความเร็วสูงสุด: 6.2 m/s (รวดเร็ว)
• ระยะขอบความเสถียร (Stability Margin): ปานกลาง
• การใช้งาน: เหมาะกับที่ราบลุ่มและต้องการความเร็วสูง
🛡️ Wave Gait (ก้าวคลื่นลูกระนาด)
• จำนวนขาค้ำพื้น: 5 ขาค้ำ / 1 ขาก้าวลอย
• Duty Factor (β): 0.83
• ความเร็วสูงสุด: 2.8 m/s (ช้าแต่มั่นคงมาก)
• ระยะขอบความเสถียร (Stability Margin): สูงสุด (รูปหลายเหลี่ยมค้ำยันกว้าง)
• การใช้งาน: ปีนขอบผาชัน หินระเกะระกะ ป้องกันการพลิกคว่ำ
สูตรวิศวกรรมการทรงตัว: ระยะขอบเสถียรภาพสถิต (Static Stability Margin: $S$) คือระยะทางที่สั้นที่สุดจากจุดศูนย์ถ่วง (CoG) ฉายลงบนระนาบไปยังขอบของรูปหลายเหลี่ยมค้ำยัน (Support Polygon) ยิ่งมีขาแตะพื้นมาก $S$ ยิ่งกว้าง หุ่นจึงไม่มีวันคว่ำ
