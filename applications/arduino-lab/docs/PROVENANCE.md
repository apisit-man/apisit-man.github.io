# Provenance

The lesson prose, prompts, specifications, model code, C++ generator, tests, report layout and helper scripts in this pack were created for this request. The public reference was inspected read-only to understand behavior. Its application bundles, CSS, textures, screenshots and meshes are not included.

The planned application must create original procedural geometry and UI. Do not imply endorsement by Arduino, the reference author, Google or IPST. Use the user's name only for author/project credit; add institutional logos only if the user supplies approved assets.

No third-party runtime library or font is bundled in this kit. Antigravity must resolve application dependencies from their official package registry, retain their license notices and record exact versions. Default system fonts require no remote download. If a self-hosted Thai font is added, include its actual license. Source URLs and inspection hashes are in the research report and RESEARCH_EVIDENCE.json; hashes identify what was inspected, not proof of licensing or a security certification.

No complete security audit of the reference application was performed. The recommended security measures concern the new implementation: no runtime secrets, no source execution, validated local data, no untrusted HTML, bounded logs and explicit resource cleanup.
