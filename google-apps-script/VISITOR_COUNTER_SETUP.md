# คู่มือการติดตั้งระบบนับสถิติผู้เข้าชมเว็บไซต์ (Visitor Counter API)
### สำหรับเว็บไซต์ ดร.อภิสิทธิ์ ธงไชย (apisit-man.github.io)

ระบบนี้เชื่อมต่อระหว่างเว็บไซต์กับ **Google Sheets** เพื่อ:
1. เก็บรวบรวมสถิติผู้เข้าชมเว็บไซต์แบบเรียลไทม์
2. แสดงผลตัวเลข **ยอดเข้าชมวันนี้** และ **ยอดเข้าชมสะสมทั้งหมด** ในส่วน Footer ของหน้าแรก
3. บันทึกสถิติรายวัน (`Daily_Stats`) และประวัติการเปิดหน้า (`Visits_Log`) อัตโนมัติใน Google Sheet ของคุณ

---

## ขั้นตอนการติดตั้ง (ใช้เวลาประมาณ 3 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheet สำหรับเก็บสถิติ
1. เปิดเบราว์เซอร์แล้วไปที่ [sheets.new](https://sheets.new)
2. ตั้งชื่อไฟล์สเปรดชีต (เช่น `Website Analytics - Apisit Tongchai`)
*(หมายเหตุ: ไม่จำเป็นต้องสร้างตารางหรือพิมพ์อะไรในชีต ระบบสคริปต์จะสร้างตารางและหัวข้อให้อัตโนมัติ)*

---

### ขั้นตอนที่ 2: นำโค้ด Apps Script ไปติดตั้ง
1. ที่เมนูด้านบนของ Google Sheet ให้คลิก: **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. ลบโค้ดที่มีอยู่ในไฟล์ `Code.gs` ออกทั้งหมด
3. เปิดไฟล์ [`google-apps-script/visitor-counter-api.gs`](visitor-counter-api.gs) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางในหน้าต่าง Apps Script
4. กดปุ่มบันทึก 💾 (Save project หรือกด `Ctrl + S`)
5. ตั้งชื่อโปรเจกต์ Apps Script ด้านบนซ้าย เช่น `Visitor Counter API`

---

### ขั้นตอนที่ 3: ปรับใช้เป็นเว็บแอป (Deploy Web App)
1. คลิกปุ่มสีน้ำเงินด้านบนขวา: **การปรับใช้ (Deploy)** ➔ **การปรับใช้ใหม่ (New deployment)**
2. คลิกไอคอนฟันเฟือง ⚙️ ทางซ้ายมือ แล้วเลือก **เว็บแอป (Web app)**
3. กำหนดค่าดังต่อไปนี้:
   * **คำอธิบาย (Description):** `Visitor Counter v1`
   * **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me)`
   * **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(⚠️ สำคัญมาก: ต้องเลือก Everyone/Anyone เพื่อให้คนทั่วไปที่เข้าเว็บเรียกนับสถิติได้)*
4. คลิกปุ่ม **ปรับใช้ (Deploy)**
5. หากระบบแสดงหน้าต่างขอสิทธิ์การเข้าถึง (Authorization):
   * คลิก **ให้สิทธิ์เข้าถึง (Authorize access)**
   * เลือกบัญชี Google ของท่าน
   * หากขึ้นเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้คลิก **ขั้นสูง (Advanced)** ➔ คลิก **ไปที่ Visitor Counter API (ไม่ปลอดภัย / Unsafe)**
   * คลิก **อนุญาต (Allow)**
6. เมื่อเสร็จสิ้น หน้าจอจะแสดง **URL ของเว็บแอป (Web App URL)** ที่มีรูปแบบ:
   ```text
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
7. คัดลอก (Copy) ลิงก์ URL ดังกล่าวเก็บไว้

---

### ขั้นตอนที่ 4: นำ Web App URL ไปใส่ในเว็บไซต์
1. เปิดไฟล์ `assets/js/visitor-counter.js`
2. ค้นหาบรรทัด:
   ```javascript
   const VISITOR_API_URL = 'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE';
   ```
3. นำ URL ที่คัดลอกมา วางแทนที่ข้อความ `'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE'` เช่น:
   ```javascript
   const VISITOR_API_URL = 'https://script.google.com/macros/s/AKfycbx.../exec';
   ```
4. บันทึกไฟล์ และ Commit / Push ขึ้น GitHub Pages เป็นอันเสร็จสมบูรณ์!

---

## ฟังก์ชันพิเศษที่ติดตั้งมาพร้อมระบบ:
* **Session Deduplication (ป้องกันการกด F5 รัวๆ):** หากผู้เข้าชมเปิดเว็บเดิมซ้ำ หรือ Refresh ภายใน Session เดิม สคริปต์หน้าเว็บจะส่งคำขอแบบ `action=get` เพื่ออ่านสถิติล่าสุดเท่านั้น โดยไม่บวกเพิ่มยอดซ้ำซ้อน
* **Auto Daily Rollover:** เมื่อข้ามเที่ยงคืนสู่เช้าวันใหม่ ระบบจะสรุปยอดของวันก่อนหน้าลงชีต `Daily_Stats` และเริ่มนับยอด `Today Views` ของวันใหม่ทันทีโดยอัตโนมัติ
* **Fallback UI:** หากยังไม่ได้ใส่ URL หรือเกิดเหตุขัดข้องทางเครือข่าย หน้าเว็บจะแสดงไอคอนสถานะอย่างสุภาพโดยไม่กระทบต่อการทำงานส่วนอื่นของเว็บไซต์
