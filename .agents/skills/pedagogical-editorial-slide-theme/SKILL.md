# Pedagogical Editorial Slide Theme (คู่มือการสร้างสไลด์และกราฟิกสไตล์วิชาการเชิงวิจารณญาณ)

ถอดรหัสอัตลักษณ์การออกแบบสไลด์และการสื่อสารระดับพรีเมียมจากเอกสารต้นแบบ **"Critical AI Literacy for Educators" (Keep the "Eh!" Alive: กระตุ้นต่อม "เอ๊ะ!")** โดย Gemini Notebook เพื่อสร้างสไลด์บรรยาย สื่อการสอน และภาพประกอบเนื้อหาที่มีพลังดึงดูดสายตา เข้าใจง่าย และกระตุ้นกระบวนการคิดอย่างลึกซึ้ง

## 1. ปรัชญาการออกแบบและอัตลักษณ์สี (Design Philosophy & Palette)

### หัวใจสำคัญของการสื่อสาร (Core Principles):
1. **Curiosity-Driven / Provocative:** ไม่ใช่แค่บอกข้อมูลตรงๆ แต่ตั้งคำถามสะกิดใจ กระตุ้นให้ผู้เรียน "เอ๊ะ!" หรือหยุดคิด (เช่น "แน่ใจนะ?", "ถ้าผิดล่ะ?")
2. **Pedagogical Metaphor:** แปลงแนวคิดเชิงนามธรรมให้เห็นเป็นรูปธรรมที่จับต้องได้ เช่น:
   - AI ไม่ใช่ผู้รอบรู้ แต่เป็น **"ตู้สล็อตเสี่ยงทายคำถัดไป" (Next-Token Predictor)**
   - ความขัดแย้งระหว่าง **"สิ่งที่ตามนุษย์มองเห็น" (Surface)** กับ **"ความจริงเชิงสถิติ" (Source/Reality)**
   - **"เครื่องจักรกล่องดำ (Black Box)"** ที่ขยายความสัญญาณเล็กๆ เกินจริง
   - **"ตราชั่งวัดคุณค่า"** ระหว่างชิ้นงานสำเร็จรูป vs กระบวนการทำความเข้าใจจริง
3. **Contrast of Authority & Human Touch:** ผสมผสานความน่าเชื่อถือแบบวิศวกรรม/พิมพ์เขียว (Tech Blueprint) เข้ากับลายมือขีดเขียนและไฮไลต์สีสดของมนุษย์ (Human Annotation)

### จานสีหลัก (Color Palette):
| บทบาทสี | ชื่อสี | รหัส HEX | ค่า RGB | หน้าที่การใช้งาน |
|---|---|:---:|:---:|---|
| **Deep Midnight Navy** | Tech Navy (Dark BG) | `#0B192C` | `(11, 25, 44)` | พื้นหลังสไลด์ธีมมืด (หน้าปก, หน้านิยามสำคัญ), กรอบ UI |
| **Light Slate Blueprint** | Tech Blueprint (Light BG) | `#EEF2F6` | `(238, 242, 246)` | พื้นหลังสไลด์ธีมสว่าง พร้อมเส้นกริดหรือเส้นผังจางๆ |

## 2. ระบบตัวอักษรและการจับคู่ฟอนต์ (Typography Hierarchy)

ระบบตัวอักษรใช้สูตรผสม 3 บุคลิก:
1. **หัวข้อและพาดหัว (Headlines):** ตัวหนา โมเดิร์น ไม่มีหัว (`Prompt`, `Google Sans`, `IBM Plex Sans Thai`, `Kanit`)
2. **เนื้อหาบรรยายและตาราง (Body Text):** อ่านง่าย เรียบร้อย สบายตา (`Sarabun`, `Noto Sans Thai`, `Leelawadee UI`)
3. **ข้อความขีดเขียน/สะกิดใจ (Handwritten Annotation):** ลายมือหวัดเป็นกันเอง คล้ายปากกาไฮไลต์ (`Itim`, `Charm`, `Mali`)

### ลำดับสเกลขนาดตัวอักษร (Type Scale - สัดส่วน 16:9):
- **Slide Main Title (หัวข้อใหญ่ประจำสไลด์):** 28–34 pt (Bold)
- **Category Kicker (ป้ายหมวดหมู่บนซ้าย):** 12–14 pt (Regular / Medium)
- **Callout Banner Text (ข้อความสรุปบนแถบล่าง):** 16–18 pt (Bold)
- **Card Heading (หัวข้อภายในการ์ด):** 18–22 pt (Bold)
- **Card Body Text (เนื้อหาคำอธิบาย):** 13–15 pt (Line Spacing 1.25x – 1.3x)
- **Handwritten Annotation (ข้อความลายมือสีเหลือง):** 22–32 pt (Bold / Cursive)

## 3. รูปแบบเลย์เอาต์การนำเสนอ 7 แม่แบบ (The 7 Presentation Archetypes)

### แบบที่ 1: Split Reality / The Torn Curtain (ซ้าย-ขวา เปรียบเทียบความจริงเบื้องหลัง)
* **การใช้งาน:** แสดงความขัดแย้งระหว่างสิ่งที่ AI แสดงออกมา (ดูดี น่าเชื่อถือ) กับความจริงทางสถิติ (การเดาคำตามความน่าจะเป็น)
* **โครงสร้าง:**
  - แบ่งสไลด์ 2 ฝั่ง (50:50 หรือ 45:55)
  - ฝั่งซ้าย: เอกสารเรืองแสงหรูหรา พร้อมลูกศรชี้ "ภาษาทางการสละสลวย", "ความมั่นใจสูง"
  - ฝั่งขวา: ภาพรอยฉีกเผยให้เห็นกลไกตู้สล็อตเสี่ยงโชค + กราฟ Decision Tree
  - ด้านล่าง: แถบสีส้มสรุปประเด็นจิตวิทยา เช่น *"Automation Bias: AI ถูกเทรนให้สร้างคำตอบที่น่าเชื่อถือ ไม่ใช่ค้นหาความจริง"*

### แบบที่ 2: The Warning Polaroid Trio (การ์ดโพลารอยด์เคสกรณีศึกษา 3 ภาพ)
* **การใช้งาน:** นำเสนอข่าวจริง เคสตัวอย่าง หรือสถานการณ์จำลองที่ AI ก่อความผิดพลาด
* **โครงสร้าง:**
  - การ์ดสไตล์โพลารอยด์ 3 ใบ วางเรียงแนวนอน แปะด้วยหมุดหรือเทปใสเสมือนจริง
  - แต่ละการ์ดมี: ภาพจริง/ภาพเจน 3D, ป้ายชื่อเคส (ภาษาอังกฤษตัวหนา), ข้อความสรุปสั้น 2 บรรทัด
  - ลูกศรหรือเส้นเชื่อมระหว่างการ์ดแสดงความสัมพันธ์
  - แถบสรุปหนาสีกรมท่าเข้มด้านล่าง: *"ความมั่นใจ ≠ ความถูกต้อง | มีอ้างอิง ≠ มีอยู่จริง"*

### แบบที่ 3: The Algorithm X-Ray Black Box (โฟลว์วิเคราะห์กล่องดำ)
* **การใช้งาน:** อธิบายกระบวนการที่ AI รับข้อมูลดิบเข้ามา แล้วตีความขยายผลเกินจริง
* **โครงสร้าง:**
  - ฝั่งซ้าย: การ์ดข้อมูลดิบ (Input) เช่น `"ส่งงานช้า 2 ครั้ง"` ส่งคลื่นชีพจร
  - ตรงกลาง: กล่องเครื่องจักร AI สีเข้ม (Black Box) มีฟันเฟืองและวงจร
  - ฝั่งขวา: ลำแสงโปรเจกเตอร์สีส้มส่องขยายไปยังกระดานรายงานผล (Output ที่เกินจริง)
  - ไฮไลต์ลายมือสีเหลืองแปะเตือน: *"AI กำลังสรุปจากข้อมูล หรือกำลังตัดสินเกินข้อมูล?"*
  - แถบล่าง: กฎเหล็กของครูผู้สอน

### แบบที่ 4: Architectural 3-Pillars (เสาหลักสถาปัตยกรรม 3 ต้น)
* **การใช้งาน:** นำเสนอนโยบาย, กรอบความคิด (Framework), หรือเสาหลักของห้องเรียน
* **โครงสร้าง:**
  - รูปทรงหน้าจั่ววิหารคลาสสิก แต่เรนเดอร์ในสไตล์ Dark Tech Blueprint
  - เสา 3 ต้น มีหลอดแก้วเรืองแสงบรรจุไอคอนกลไกภายใน
  - แผ่นโพสต์อิทสีเหลือง (Sticky Note) แปะขวางฐานเสาด้วยข้อความสำคัญ
  - คำบรรยายกำกับแต่ละเสาซ้าย กลาง ขวา สั้น กระชับ ชัดเจน

### แบบที่ 5: The 5-Stage Node Pipeline (เส้นทางโฟลว์ 5 จุดเชื่อมโยง)
* **การใช้งาน:** อธิบายขั้นตอนการทำงาน การเรียนรู้ หรือกระบวนการก่อน-ระหว่าง-หลังใช้ AI
* **โครงสร้าง:**
  - เส้นท่อสายพานแนวนอนสีน้ำเงินเข้ม พาดกลางสไลด์
  - วงกลม Node 5 จุด พร้อมแสงเรืองรองสีเหลืองนีออนและฟ้า
  - ปีกกากำกับแบ่งช่วง: `ก่อนใช้` (จุด 1) | `ระหว่างใช้` (จุด 2-3) | `หลังใช้` (จุด 4-5)
  - แถบสีเข้มสรุปคติประจำสไลด์ด้านล่าง

### แบบที่ 6: The AI Assessment Scale (หอสัญญาณไฟประเมินระดับ)
* **การใช้งาน:** ตารางเทียบระดับ (Scale / Rubric) เช่น ระดับ 1 ถึง 5
* **โครงสร้าง:**
  - ฝั่งซ้าย: รายการข้อความพร้อมคำอธิบายแต่ละระดับ
  - ฝั่งขวา: หอคอยสัญญาณไฟแนวตั้ง 5 ชั้น (แดง -> ส้ม -> เหลือง -> เขียวอ่อน -> เขียวเข้ม)
  - ลายเส้นตารางกริดสมุดกราฟ (Graph Paper Grid) เป็นพื้นหลัง
  - ป้ายไฮไลต์สีเหลืองแปะเตือนเรื่องความโปร่งใส

### แบบที่ 7: Concrete Science Experiment vs AI Output (ตารางเทียบผลแล็บจริง vs AI)
* **การใช้งาน:** แสดงตัวอย่างการสอนในชั้นเรียนจริงที่จับผิด AI ด้วยผลการทดลองเชิงประจักษ์
* **โครงสร้าง:**
  - ฝั่งซ้าย: ตารางข้อมูลผลการทดลองจริง (The Evidence) มีวงกลมสีเหลืองวงข้อมูลสำคัญ
  - ฝั่งขวา: กรอบหน้าต่าง UI สีน้ำเงิน แสดงคำตอบของ AI พร้อมเส้นกากบาทสีส้มทับข้อความที่มั่ว
  - ด้านล่าง: กล่องพิมพ์เขียวสีน้ำเงินเข้มสรุป "Teacher's Blueprint" (โจทย์ + กระบวนการ)

## 5. การเรียกใช้ผ่าน Python-pptx

สามารถสร้างไฟล์นำเสนออัตโนมัติด้วยโมดูล [slide_builder.py](file:///C:/Users/atong/.gemini/config/skills/pedagogical-editorial-slide-theme/scripts/slide_builder.py):

```python
from scripts.slide_builder import (
    create_presentation, set_slide_background, add_header,
    add_banner_footer, add_handwritten_callout, add_card,
    BG_DEEP_NAVY, BG_LIGHT_BLUE, ACCENT_CYBER_YELLOW, TEXT_TITLE_LIGHT
)

prs = create_presentation()
blank_layout = prs.slide_layouts[6]

# สร้างสไลด์ธีมมืด
slide1 = prs.slides.add_slide(blank_layout)
set_slide_background(slide1, BG_DEEP_NAVY)
add_header(slide1, "Keep the 'Eh!' Alive: กระตุ้นต่อม 'เอ๊ะ!'", kicker_text="Digital Pedagogy", is_dark_mode=True)
add_handwritten_callout(slide1, "แน่ใจนะ?", left=8.5, top=1.2, width=3.0, height=1.0, color=ACCENT_CYBER_YELLOW, font_size=28)
add_banner_footer(slide1, "วิถีเอาตัวรอดและสร้างสรรค์การเรียนรู้ในยุคที่ AI ตอบถูกใจ... แต่(อาจ)ไม่ถูกต้อง")
```
