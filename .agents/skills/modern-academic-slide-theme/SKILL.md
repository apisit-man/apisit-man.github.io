# Modern Academic & Framework Slide Theme (คู่มือการสร้างสไลด์ตามธีมวิชาการร่วมสมัย)

แนวทางการออกแบบและสร้างสไลด์นำเสนอทางวิชาการ นโยบายการศึกษา และกรอบสมรรถนะ (เช่น กรอบสมรรถนะความฉลาดรู้ปัญญาประดิษฐ์ AI Literacy Framework / สสวท.) โดยถอดรหัสอัตลักษณ์จากไฟล์ `slid theme.pptx` เพื่อให้งานนำเสนอมีความสง่างาม น่าเชื่อถือ สดใสมีพลัง และจัดวางข้อมูลเป็นระบบอ่านง่ายระดับสากล

## 2. ระบบตัวอักษรและระดับชั้นสายตา (Typography & Hierarchy)

### ฟอนต์แนะนำ (Font Priority Stack):
1. **ภาษาไทยและอังกฤษ:** `Google Sans` / `Google Sans Medium` (ฟอนต์ต้นฉบับในธีม)
2. **ฟอนต์ทางเลือกคุณภาพสูง:** `IBM Plex Sans Thai`, `Noto Sans Thai`, หรือ `Anuphan`
3. **ฟอนต์มาตรฐานประจำระบบ (System Fallback):** `Leelawadee UI`

> [!IMPORTANT]
> **การเว้นระยะบรรทัด (Line Spacing):** สำหรับภาษาไทยต้องตั้งค่า Line Spacing ไว้ที่ **1.25x – 1.35x** เสมอ เพื่อป้องกันสระบน-ล่างและวรรณยุกต์ซ้อนทับกัน

### สเกลขนาดตัวอักษรมาตรฐาน (Type Scale):
* **หน้าปก: ชื่อเรื่องหลัก (Cover Title):** 38–42 pt (Bold, สีขาว `#FFFFFF`)
* **หน้าปก: ชื่อเรื่องภาษาอังกฤษ/คำอธิบายรอง:** 20–22 pt (Regular/Medium, สีฟ้าอ่อน `#9FC0FF`)
* **หน้าปก: แถบสถานะด้านล่าง:** 16–17 pt (Medium, สีขาวบนแถบสีกรมท่าโปร่ง)
* **หน้าเนื้อหา: ป้ายหมวดหมู่บนหัวเรื่อง (Category Kicker):** 11.5–12 pt (Bold, สี Electric Cobalt `#1640C9`)
* **หน้าเนื้อหา: ชื่อสไลด์หลัก (Slide Title):** 30–31 pt (Bold, สี Deep Midnight Navy `#16213E`)
* **หน้าเนื้อหา: ข้อความเกริ่นนำใต้ชื่อสไลด์ (Lead Subtitle):** 15–16 pt (Regular, สี Slate `#5C6B8A`)
* **หัวข้อภายในการ์ด (Card Heading):** 18–19 pt (Bold, สี Deep Navy หรือ Cobalt)
* **รหัสข้อหรือเลขประจำการ์ด (Card Tag / Numeral):** 19–20 pt (Bold, เช่น `๑.๖`, `๒.๕` หรือตัวเลขอารบิก)
* **เนื้อหาบรรยายภายในการ์ด (Body Text):** 13.5–15 pt (Regular, สี `#16213E`)
* **ป้ายระบุจำนวน/แท็กท้ายการ์ด (Pill Tag):** 12–13 pt (Bold, เช่น `6 สมรรถนะ`)
* **ข้อความท้ายสไลด์ซ้าย (Footer Status / Watermark):** 9–10 pt (Regular, สี `#5C6B8A`, เช่น `"เอกสารฉบับร่างเพื่อการพิจารณา"`)
* **เลขหน้าขวาล่าง (Slide Number):** 10–11 pt (Regular, สี `#5C6B8A`)

## 4. รูปแบบเลย์เอาต์หลัก 8 แบบ (The 8 Layout Archetypes)

### แบบที่ 1: Dark Navy Cover Slide (หน้าปกเทคโนโลยีสีกรมท่าลึก)
* **พื้นหลัง:** ภาพกราฟิกเทคโนโลยีโทนน้ำเงินเข้ม หรือสีทึบ `#071E3D` / `#16213E`
* **โลโก้:** มุมบนซ้าย (`Left=0.80"`, `Top=0.61"`, `Width=2.98"`, `Height=0.95"`)
* **หัวเรื่องหลัก:** 38 pt สีขาวคมชัด (`Left=0.80"`, `Top=2.17"`)
* **หัวเรื่องรอง:** 21 pt สีฟ้าเทคโนโลยี `#9FC0FF` (`Left=0.80"`, `Top=4.68"`)
* **แถบกำกับเอกสารล่าง:** แถบยาวเต็มความกว้างสไลด์ (`Top=6.40"`, `Height=0.62"`) ตัวอักษรสีขาว 17 pt

### แบบที่ 2: 3-Card Focus with Badges & Stars (การ์ด 3 คอลัมน์พร้อมป้ายดาวเด่น)
เหมาะสำหรับสรุป 3 ประเด็นสำคัญ หรือสมรรถนะที่เป็นเอกลักษณ์:
* **การ์ด 3 ใบ:** `Top=2.30"`, `Height=4.52"`, `Width=3.90"` (วางที่ `Left=0.60"`, `4.70"`, `8.80"`)
* **พื้นผิวการ์ด:** สีอบอุ่น `#F8E3C4` (ขอบ `#F0DDB0`) หรือสีฟ้าเย็น `#F6F8FC` (ขอบ `#E1E8F7`)
* **ป้ายดาวขวาบนการ์ด:** ดาวสีทอง `★` (`#F5A623`, ขนาด 20 pt)
* **วงกลมไอคอนซ้ายบนการ์ด:** วงกลมขนาดเส้นผ่านศูนย์กลาง `0.65"` เติมสีส้มทอง `#F5A623` หรือน้ำเงิน `#2E6BFF`
* **รหัสข้อเด่น:** เช่น `๑.๖`, `๒.๕` ตัวหนา 19 pt สีน้ำเงินสด `#1640C9`
* **หัวข้อการ์ด:** 19 pt Bold สี Deep Navy
* **เส้นคั่นกลางบาง:** เส้นแนวนอนสี `#E0850F` หรือ `#2E6BFF` แบ่งหัวข้อกับคำอธิบาย
* **เนื้อหาอธิบาย:** 15–16 pt อ่านสบายตา

### แบบที่ 3: 4-Domain Multi-Color Pillars (4 เสาหลักแยกตามสีธีม)
เหมาะสำหรับนำเสนอกรอบโดเมน 4 มิติหลัก (เช่น Living with AI, AI Creation, AI Management, AI Design):
* **การ์ดทรงสูง 4 ใบ:** `Top=1.71"`, `Height=4.90"`, `Width=2.96"` (วางที่ `Left=0.55"`, `3.66"`, `6.77"`, `9.88"`)
* **รหัสสีประจำ 4 โดเมน:**
  1. โดเมน 1 (การอยู่ร่วม): พื้น `#1F4E79`, วงกลม `#3D7CB8`, ป้ายล่าง `#C9DAF8`
  2. โดเมน 2 (การสร้างสรรค์): พื้น `#177A6F`, วงกลม `#76A5AF`, ป้ายล่าง `#D0E0E3`
  3. โดเมน 3 (การจัดการ): พื้น `#B45F06`, วงกลม `#E0850F`, ป้ายล่าง `#FFF2CC`
  4. โดเมน 4 (การออกแบบ): พื้น `#7030A0`, วงกลม `#9C5EC9`, ป้ายล่าง `#D9D2E9`
* **องค์ประกอบในการ์ด:** ตัวเลขไทยกลมสีขาวบนการ์ดเข้ม, หัวข้อภาษาไทยและอังกฤษ, ข้อความนิยาม, ป้ายบอกจำนวนสมรรถนะด้านล่าง (เช่น `6 สมรรถนะ`)

### แบบที่ 4: 5-Stage Educational Progression (ลำดับขั้นพัฒนาการผู้เรียน)
เหมาะสำหรับแสดงพัฒนาการตามระดับการศึกษา:
* แบ่งเป็นขั้นบันได 5 ระดับ: ประถม, ม.ต้น, ม.ปลาย, อาชีวะ, อุดมศึกษา
* มีการ์ดแถบขวาพิเศษสำหรับ **"ครูและบุคลากรทางการศึกษา"** สีส้มทอง `#F5A623` แสดงบทบาทสนับสนุนทุกระดับ

### แบบที่ 5: 6-Item Numbered Grid (กริด 6 เป้าหมาย/หลักการ)
* แบ่ง 2 แถว × 3 คอลัมน์ หรือการ์ดคู่แนวนอน
* แต่ละข้อมีวงกลมตัวเลขไทย `๑` ถึง `๖` ในวงกลมสีฟ้าอ่อนหรือสีกรมท่า ข้อความหัวข้อเด่นและคำขยายกระชับ

### แบบที่ 6: Multi-Phase Roadmap / Timeline (แผนผังเส้นทางและขั้นตอนต่อไป)
เหมาะสำหรับแสดง Timeline แผนงานอนาคต:
* **แถบระบุระยะ Phase I:** แถบสีน้ำเงิน `#1640C9` ยาวพาดบนการ์ด (`Top=1.68"`, `Height=0.32"`)
* **การ์ดขั้นตอน 5 ใบ:** `Width=2.00"`, `Height=3.17"`, สี `#F6F8FC` ขอบ `#E1E8F7`
  - ไอคอนวงกลม `#2E6BFF` ด้านบน
  - หัวข้อกิจกรรม (16 pt Bold)
  - วันที่กำกับด้านล่าง (เช่น `19 ส.ค. 69`, `ก.ย. 69`, `ต.ค. 69 (tentative)`)
* **แถบระบุระยะ Phase II:** แถบสีม่วง `#5B3F85` ด้านล่าง พร้อมกรอบข้อความระยะการขับเคลื่อนนโยบาย

### แบบที่ 7: 2-Column Institutional Partnership (การเปรียบเทียบคู่ 2 องค์กร)
* การ์ดกว้าง 2 ใบเคียงกัน (ความกว้าง 5.3" ต่อใบ)
* คอลัมน์ซ้าย: คณะยกร่าง / ผู้พัฒนา
* คอลัมน์ขวา: หน่วยงานร่วมพิจารณา / ผู้มีส่วนได้ส่วนเสีย

### แบบที่ 8: Rubric Matrix Table (ตารางประเมินสมรรถนะตามช่วงชั้น)
* ตารางมาตรฐาน ขอบตารางมน หัวตารางสีเข้ม มีการไฮไลต์เซลล์
* ด้านล่างมี Legend อธิบายสัญลักษณ์: `● = เข้าใจ · ●● = ประยุกต์ · ●●● = ต่อยอด`

## 5. แม่แบบโค้ด Python สำหรับสร้างสไลด์ (Python-pptx Generator Code)

ในการสร้างสไลด์ ให้ใช้สคริปต์ตัวช่วยโมดูลาร์ `scripts/slide_builder.py` หรือเขียนฟังก์ชันสร้างสไลด์ตามโครงสร้างต่อไปนี้:

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.shapes import MSO_SHAPE

# 1. กำหนดระบบสีตามธีม
COLOR_NAVY = RGBColor(22, 33, 62)       # #16213E
COLOR_COBALT = RGBColor(22, 64, 201)    # #1640C9
COLOR_SKY = RGBColor(46, 107, 255)      # #2E6BFF
COLOR_AMBER = RGBColor(245, 166, 35)    # #F5A623
COLOR_CARD_COOL = RGBColor(246, 248, 252)  # #F6F8FC
COLOR_BORDER_COOL = RGBColor(225, 232, 247)# #E1E8F7
COLOR_CARD_WARM = RGBColor(248, 227, 196)  # #F8E3C4
COLOR_BORDER_WARM = RGBColor(240, 221, 176)# #F0DDB0
COLOR_MUTED = RGBColor(92, 107, 138)    # #5C6B8A

FONT_FAMILY = "Google Sans" # หรือ "IBM Plex Sans Thai" / "Leelawadee UI"

def add_standard_header(slide, kicker_text, title_text, subtitle_text=None, logo_path=None):
    """สร้าง Header มาตรฐานประจำสไลด์"""
    # Kicker (ป้ายหมวดหมู่)
    kb = slide.shapes.add_textbox(Inches(0.60), Inches(0.42), Inches(10.0), Inches(0.32))
    p_k = kb.text_frame.paragraphs[0]
    p_k.text = kicker_text
    p_k.font.name = FONT_FAMILY
    p_k.font.size = Pt(11.5)
    p_k.font.bold = True
    p_k.font.color.rgb = COLOR_COBALT
    
    # Title (หัวข้อใหญ่)
    tb = slide.shapes.add_textbox(Inches(0.60), Inches(0.72), Inches(11.5), Inches(0.85))
    p_t = tb.text_frame.paragraphs[0]
    p_t.text = title_text
    p_t.font.name = FONT_FAMILY
    p_t.font.size = Pt(30)
    p_t.font.bold = True
    p_t.font.color.rgb = COLOR_NAVY
    
    # Subtitle (เกริ่นนำ)
    if subtitle_text:
        sb = slide.shapes.add_textbox(Inches(0.60), Inches(1.52), Inches(12.1), Inches(0.40))
        p_s = sb.text_frame.paragraphs[0]
        p_s.text = subtitle_text
        p_s.font.name = FONT_FAMILY
        p_s.font.size = Pt(15)
        p_s.font.color.rgb = COLOR_MUTED

    # Footer Watermark & Status
    fb = slide.shapes.add_textbox(Inches(0.60), Inches(7.05), Inches(6.0), Inches(0.30))
    p_f = fb.text_frame.paragraphs[0]
    p_f.text = "เอกสารฉบับร่างเพื่อการพิจารณา"
    p_f.font.name = FONT_FAMILY
    p_f.font.size = Pt(9)
    p_f.font.color.rgb = COLOR_MUTED
```
