# IPST Presentation Slides Design Skill (สไลด์มาตรฐาน สสวท.)

ทักษะและแนวทางปฏิบัติในการออกแบบและสร้างสไลด์การนำเสนอระดับมืออาชีพตามอัตลักษณ์ของ **สถาบันส่งเสริมการสอนวิทยาศาสตร์และเทคโนโลยี (สสวท. / IPST)** สำหรับการบรรยาย อบรมเชิงปฏิบัติการ และสื่อการเรียนการสอนทางวิทยาศาสตร์ คณิตศาสตร์ และเทคโนโลยี

## 2. ระบบสเกลตัวอักษรและความสมดุล (Strict Typographic Hierarchy)

> [!IMPORTANT]
> **กฎเหล็ก "Avoid the 11pt Trap":** ห้ามใช้ฟอนต์เนื้อหาขนาด 10–11 pt บนสไลด์นำเสนอเด็ดขาด เพราะเป็นขนาดสำหรับเอกสาร A4 ไม่ใช่จอฉาย ให้ปฏิบัติตามอัตราส่วนขนาดมาตรฐานนี้อย่างเคร่งครัด

### ตารางสเกลขนาดตัวอักษรมาตรฐาน สสวท. (16:9 Widescreen)
| ตำแหน่งองค์ประกอบ | ขนาดแนะนำ | น้ำหนัก (Weight) | สีข้อความ |
|---|:---:|:---:|---|
| **หน้าปก: หัวข้อหลัก (Cover Title)** | **38–42 pt** | หนา (Bold) | สีขาว (`#FFFFFF`) |
| **หน้าปก: หัวข้อย่อย (Cover Subtitle)** | **18–20 pt** | กึ่งหนา (Semi-bold) | สีฟ้าเทคโนโลยี (`#0099DA`) |
| **หน้าปก: เป้าหมาย/สาระสำคัญ** | **13.5–15 pt** | บูลเล็ตหนา + เนื้อหาปกติ | ขาวนวล / เหลืองทอง |
| **หน้าเนื้อหา: ป้ายหมวดหมู่ (Section Tag)** | **12 pt** | หนา (Bold) | สีกรมท่า (`#003366`) ในกล่องฟ้าอ่อน |
| **หน้าเนื้อหา: หัวข้อสไลด์ (Slide Title)** | **28–30 pt** | หนา (Bold) | สีกรมท่า สสวท. (`#003366`) |
| **หน้าเนื้อหา: หัวข้อย่อย (Slide Subtitle)** | **15–16 pt** | ปกติ (Regular) | สีฟ้าเทคโนโลยี (`#0099DA`) |
| **หัวข้อประจำการ์ด (Card Heading)** | **16–18 pt** | หนา (Bold) | สีกรมท่า / สีส้มเน้น / สีเขียว |
| **หัวข้อย่อยในการ์ด/ภาษาอังกฤษ (Card Sub)** | **11.5–12.5 pt** | ปกติ / ตัวเอียง | สีเทากลาง (`#475569`) |
| **เนื้อหาในการ์ด (Card Body Text)** | **13.5–14.5 pt** | Bold-Lead Bullet | สีเทาเข้ม (`#1E293B`) |
| **กริด 6 ขั้นตอน (Dense 6-Grid Steps)** | **13–13.5 pt** | หนาที่หัวข้อ + ปกติ | ดำเข้ม / เทาเข้ม |
| **เลขหน้าและสถานะ (Slide Counter)** | **11.5–12 pt** | ปกติ | สีเทา (`#475569`) |

### สรีระอักษรภาษาไทย (Thai Script Anatomy):
* ใช้ฟอนต์ **`Leelawadee UI`** เป็นค่าเริ่มต้น (หรือ `TH Sarabun New / Sarabun` สำหรับงานทางการ)
* **ระยะห่างบรรทัด (Line Spacing):** ต้องตั้งไว้อย่างน้อย **1.25x – 1.35x** เพื่อป้องกันไม่ให้สระบน/วรรณยุกต์ซ้อนทับหรือเบลอ

## 3. สถาปัตยกรรมข้อมูล: เทคนิค "Bold-Lead Bullets"

เพื่อรักษาขนาดตัวอักษรให้อ่านง่าย (13.5–14.5 pt) โดยที่เนื้อหาไม่ล้นการ์ด ให้เขียนข้อความเป็นแบบ **หัวข้อหนานำ + ขยายความสั้น 1 ประโยค**:

```python
# ตัวอย่างการสร้าง Bold-Lead Bullet ใน python-pptx
p = tf.add_paragraph()
p.space_after = Pt(8)

# ส่วนหัวข้อหนานำสายตา (Tier 2 / Scanning Eye)
r1 = p.add_run()
r1.text = "• คิดแก้ปัญหาเชิงระบบ: "
r1.font.bold = True
r1.font.size = Pt(14)
r1.font.color.rgb = IPST_NAVY

# ส่วนคำอธิบายกระชับ (Tier 3 / Payload)
r2 = p.add_run()
r2.text = "มองเห็นภาพรวมและความสัมพันธ์ระหว่างชิ้นส่วนย่อย ผลกระทบต่อสิ่งแวดล้อม"
r2.font.bold = False
r2.font.size = Pt(14)
r2.font.color.rgb = TEXT_DARK
```

## 4. กฎการวางโลโก้ IPST (Logo Placement Guidelines)

1. **หน้าปก (Cover Slide - Slide 1):**
   * วางโลโก้บนการ์ดขาวขอบมนที่ **มุมบนซ้าย** (Top-Left) ขนาดประมาณ กว้าง 1.4" × สูง 1.44"
   * เคียงคู่กับชื่อสถาบันภาษาไทย ภาษาอังกฤษ และชื่อหลักสูตรอบรม
2. **สไลด์เนื้อหา (Content Slides - Slide 2–19):**
   * วางโลโก้ขนาดย่อแบบ Compact ที่ **มุมบนขวา** (Top-Right) ขนาดสูงประมาณ 0.65" – 0.68"
   * วางอยู่ในระนาบเดียวกับแถบเลขหน้าและป้ายหมวดหมู่
3. **หน้าสรุป (Closing Slide - Slide 20):**
   * วางโลโก้คู่กับหัวข้อสรุปและเวทีซักถาม (Q&A)

## 5. การจัดวางพื้นที่และสถาปัตยกรรมเลเอาต์สมัยใหม่ (Modern Non-Column Layout Archetypes)

> [!IMPORTANT]
> **กฎเหล็ก "Avoid Column Fatigue" (ห้ามใช้เลเอาต์แบ่งคอลัมน์ซ้ำกันทุกหน้า):**
> สไลด์สมัยใหม่ต้องไม่วางการ์ดแนวตั้ง 2-3-4 คอลัมน์ซ้ำกันทุกสไลด์ เพราะจะทำให้ผู้ฟังเกิดความล้าสายตาและดูเป็นบล็อกสำเร็จรูป ให้สลับจังหวะสายตา (Visual Rhythm) ด้วย **7 โครงสร้างเลเอาต์สร้างสรรค์ (Creative Layout Archetypes)** ด้านล่างนี้ โดยห้ามใช้เลเอาต์แบบเดียวกันติดกันเกิน 2 หน้า

### 7 โครงสร้างเลเอาต์มาตรฐานยุคใหม่ (`layout` parameter ใน `generate_ipst_slides.py`):
1. **`hero_quote_horizontal` (แบนเนอร์วิสัยทัศน์เต็มความกว้าง + แถบแนวนอนเรียงซ้อน 3 ชั้น):**
   * ด้านบนเป็นกล่องแบนเนอร์สีกรมท่าเข้ม (`#003366`) เต็มความกว้าง `11.73"` เน้นข้อความวิสัยทัศน์หรือสาระสำคัญขนาดใหญ่ (`19–20 pt`)
   * ด้านล่างเรียงเป็น **แถบแนวนอน (Horizontal Strips)** 3 ชั้น ด้านซ้ายของแต่ละแถบมีป้าย Badge สีเข้มระบุหัวข้อ ด้านขวาเป็นเนื้อหาแนวนอนอ่านสบายตา
2. **`bento_grid` (Bento Box Grid แบบอสมมาตรสไตล์โมเดิร์น):**
   * ด้านซ้ายเป็น **Hero Bento Card** ขนาดใหญ่พื้นสีกรมท่าเข้ม (`4.5" × 4.8"`) สำหรับภารกิจหรือประเด็นหลักที่สำคัญที่สุด
   * ด้านขวาแบ่งเป็น **1 การ์ดแนวนอนยาวด้านบน** (`6.88" × 2.25"`) และ **2 การ์ดจัตุรัสคู่ด้านล่าง** (`3.28" × 2.25"`) สร้างจุดโฟกัสสายตาที่ไม่จำเจ
3. **`hub_spoke` (แผนภาพศูนย์กลาง Hub & Spoke Ecosystem):**
   * ตรงกลางสไลด์เป็นวงกลม/แคปซูลแกนกลาง (**Central Hub**) สีกรมท่าขอบฟ้าเชื่อมโยงกับ **4 กล่องบริวาร (Quadrant Spokes)** มุมซ้ายบน ขวาบน ซ้ายล่าง และขวาล่าง พร้อมเส้นเชื่อมโยงแสดงความสัมพันธ์เชิงระบบ
4. **`process_flow` (ลูกศรลำดับขั้น Connected Pipeline Flow):**
   * แสดงกระบวนการต่อเนื่องด้วยป้ายวงกลมตัวเลข (`01` – `06`) พร้อมลูกศรเชื่อมโยงแนวนอน (`➔`) และแถบสรุปผลป้อนกลับ (Feedback Loop Banner) ด้านล่าง แทนการวางตารางแข็งๆ
5. **`stat_spotlight` (แถบตัวเลขสถิติเด่น Big Metric Callouts + แถบเจาะลึกแนวนอน):**
   * ครึ่งบนแสดง **3 ตัวเลขสถิติสำคัญ (Big Numbers `32–36 pt`)** พร้อมหน่วยและคำอธิบายสั้น
   * ครึ่งล่างเป็น **2 แถบ Spotlight แนวนอน** เปรียบเทียบหรือเจาะลึกโครงการสำคัญ (เช่น พสวท. และโอลิมปิกวิชาการ)
6. **`stepped_roadmap` (แผงข้อมูลเชิงลึกด้านซ้าย + บันไดก้าวหน้า 3 ระยะด้านขวา):**
   * ด้านซ้ายเป็น **Insight Panel** พื้นสีกรมท่าสรุปฐานข้อมูลสำคัญ (เช่น ศูนย์แห่งชาติ PISA & TIMSS)
   * ด้านขวาเป็น **แถบบันได 3 ระยะ (Stepped Roadmap Bars)** เยื้องระดับแสดงทิศทางการพัฒนาจากปัจจุบันสู่อนาคต
7. **`cards` (คอลัมน์มาตรฐาน 2, 3 หรือ 4 คอลัมน์):**
   * ใช้เฉพาะหน้าที่ต้องการเปรียบเทียบหมวดหมู่ที่มีน้ำหนักเท่ากัน (ระยะเว้นขอบซ้าย-ขวา `0.8"`, ระยะห่างการ์ด `0.35"`)

## 6. Speaker Notes (บทพูดวิทยากร)
ทุกสไลด์จะต้องมีบันทึกบทพูดวิทยากรใน Notes Pane เสมอ:
* `[เวลาบรรยายโดยประมาณ]: 4-5 นาที`
* `[Speaker Notes / บทพูดวิทยากร]: สคริปต์คำพูด เทคนิคการถาม และประเด็นเน้นย้ำ`
