# ของใช้ไปบ้านไหน?

เกม HTML/CSS/JavaScript สำหรับเด็กปฐมวัย เล่นได้ทั้งมือถือ แท็บเล็ต คอมพิวเตอร์ และจอโปรเจกเตอร์

## วิธีใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` เพื่อทดลองเล่นในเครื่อง
3. อัปโหลดโฟลเดอร์ทั้งหมดไปยังเว็บไซต์หรือ GitHub Pages

## โครงสร้าง

- `index.html` หน้าเกมทั้งหมด
- `css/style.css` รูปแบบและ Responsive layout
- `js/data.js` รายการบัตร 24 ใบ และหมวด 4 ห้อง
- `js/audio.js` เสียงอ่านภาษาไทยด้วย Web Speech API และเสียงเอฟเฟกต์
- `js/game.js` ระบบเกม คะแนน ระดับ คำใบ้ หยุดพัก และสรุปผล

## ฟังก์ชันที่มี

- 3 ระดับ: 2, 3 และ 4 หมวด
- เลือก 8, 10 หรือ 12 บัตรต่อรอบ
- เลือกความเร็ว
- โหมดเด็กเล่นเองและโหมดครูเล่นกับทั้งห้อง
- เสียงอ่านคำศัพท์ภาษาไทยจากเบราว์เซอร์
- ตอบผิดแล้วลองใหม่ พร้อมคำใบ้
- คะแนน ดาว และสรุปข้อที่ควรทบทวน
- บันทึกคะแนนสูงสุดด้วย localStorage
- รองรับปุ่มตัวเลข 1–4 และ Spacebar สำหรับหยุดเกม

## นำขึ้น GitHub Pages

วางโฟลเดอร์ไว้ใน repository เช่น

```text
learning-games/home-sort-game/
```

จากนั้นเปิดลิงก์

```text
https://USERNAME.github.io/REPOSITORY/learning-games/home-sort-game/
```

## การแก้ไขบัตร

เปิดไฟล์ `js/data.js` แล้วเพิ่มหรือแก้ไขรายการใน `GAME_ITEMS`

```js
{
  id: "soap",
  word: "สบู่",
  emoji: "🧼",
  category: "bathroom",
  hint: "ใช้ล้างมือและทำความสะอาดร่างกาย"
}
```

หมวดที่รองรับในรุ่นนี้:

- `bedroom`
- `kitchen`
- `bathroom`
- `classroom`

## หมายเหตุเรื่องเสียง

เกมใช้ Web Speech API จึงไม่ต้องมีไฟล์ MP3 แยก เสียงภาษาไทยขึ้นอยู่กับเสียงที่ติดตั้งในระบบและเบราว์เซอร์ของผู้เล่น Chrome และ Edge รุ่นใหม่มักใช้งานได้ดี
